No visible focus indicator on interactive elementsC1

All focusable elements (global) heuristic-critic WCAG 2.4.11

Add focus rings with ≥3:1 contrast and area ≥ perimeter × 2 CSS px, per WCAG 2.2 Focus Appearance.

Serious

Placeholder text used as label substituteS1

Create item form · Name & Email fields heuristic-critic WCAG 1.3.1, 2.4.6

Add persistent visible labels above each input; placeholders vanish on typing and are not reliable accessible names.

Image placeholder has no alt text or declared purposeS2

Large grey block between Recent accounts & Create item form heuristic-critic WCAG 1.1.1

Add descriptive alt text if informative, or aria-hidden=“true” if decorative.

Mode toggle has insufficient target size and ambiguous labelS3

Top nav · “MODE: LIGHT” control heuristic-critic WCAG 2.5.8

Ensure target area ≥ 24×24 px (ideally 44×44 px); apply a clear interactive affordance (e.g. chevron icon).

Status badges rely solely on color to convey meaningS4

Recent accounts table · Status column heuristic-critic WCAG 1.4.1

Add an icon or textual prefix alongside color fills so meaning is perceivable without color vision.

Account name links lack descriptive accessible namesS5

Recent accounts table · Name column heuristic-critic WCAG 2.4.6, 4.1.2

Add visually-hidden context text (e.g. “View Northwind Labs account”) to distinguish links for screen-reader users.

Moderate

Raw oklab() overlay color, not a design tokenM1

Overlay / modal backdrop design-system-checker

Replace with a named semantic token (e.g. --color-overlay); raw oklab() values are not portable or token-driven.

Off-palette near-black rgb(10,10,10)M2

Text or background element design-system-checker

Consolidate to the nearest palette token (e.g. --color-neutral-950); the palette already uses rgb(15,23,42) as its darkest neutral.

Danger colors may be hard-coded, not tokenisedM3

Alert / error component design-system-checker

Confirm rgb(239,68,68) and rgb(254,226,226) map to semantic tokens (--color-danger, --color-danger-subtle) rather than raw utility classes.

Email notifications toggle missing state announcement and groupingM4

Footer · email notifications toggle heuristic-critic WCAG 4.1.2

Competing primary actions; no visual hierarchy between CTAsM5

Header “EXPORT REPORT” vs. form “Submit” heuristic-critic

Adopt distinct primary and secondary button styles so users can immediately identify the page’s main call-to-action.

Minor

Extreme border-radius value (3.35544e+07px)m1

Pill / badge / tag element design-system-checker

Replace with a canonical token (--radius-full: 9999px) for readability and consistency.

Negative spacing (-1px)m2

Border-offset or margin element design-system-checker

If intentional, map to a named token (--spacing-border-offset); otherwise align to the 4 px grid.

Sub-grid micro-spacing (2px)m3

Unknown element design-system-checker

If used for focus-ring offset, tokenise as --spacing-focus-ring: 2px; otherwise align to the 4 px base grid.

What looks good

  • Spacing scale (8 / 16 / 32 px) maps cleanly to the 4 px base grid.
  • Type ramp (12 / 14 / 16 / 20 / 24 px) is well-structured and consistent.
  • Border radii (4 / 8 px plus pill) form a clean two-step scale.
  • Core neutral palette (rgb(15,23,42) to rgb(248,250,252)) is a coherent slate ramp.
